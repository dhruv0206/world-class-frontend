# Stripe — stripe.com
Analyzed: 2026-05-16

## Snapshot
- Category: SaaS (Fintech)
- Feel: Engineered, Reliable, Cutting-edge
- Stack: Next.js + Framer Motion + Vanilla CSS

## Layout & Spacing
Flexible 12-column grid, max-width 1200px - 1440px. Generous macro-whitespace (120px - 160px) delineating sections with alternating background colors (White, Light Gray, Deep Navy). Functional and tight micro-spacing. Left-aligned predominantly.

## Typography  
Proprietary sans-serif. Highly readable with multiple weights. Headings have tight tracking. Body text is 18px, generous line height. Clean and corporate but distinctly modern.

## Color System
Light mode dominant with crisp white (#FFFFFF) and off-white/gray backgrounds. Text is dark slate/black (#0A2540). Signature Blurple/Indigo (#635BFF) accent color, plus vivid secondary gradients.

## Motion & Animation
Silky smooth transitions, 3D rotating graphics in the hero, isometric grid animations. High-performance canvas/WebGL animations. Snappy menu hovers. Functional and expressive.

## Standout Patterns
Interactive globe/grids. Diagonal background slashes. The complex, fluid mega-menu. Code snippet tabs that switch smoothly.

## Hermes Implementation Notes
- Animation library to use: Framer Motion
- Key techniques: Multi-step layout transitions, subtle scaling on hover
- Font stack: system-ui, -apple-system, sans-serif
- Color tokens: #FFFFFF bg, #0A2540 text, #635BFF accent
