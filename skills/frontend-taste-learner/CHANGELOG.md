# Changelog

## [0.3.0] - 2026-05-16
### Added
- Analyzed: Linear.app
- Key insight: Linear defines the benchmark for "Dark SaaS". The deep black backgrounds (#000000) contrasting with stark white headers and muted silver body text create a highly engineered, objective aesthetic.
- Updated design tokens to include Linear's signature dark mode text contrasts and structural white space.

## [0.2.0] - 2026-05-16
### Added
- Analyzed: Attio.com
- Key insight: Visible 1px grid structures (the "technical/editorial" aesthetic) are highly effective at organizing white space and conveying a premium, engineered feel. 
- Updated design tokens to include the grid-line aesthetic.
